The `pb;sync` command is the root command for managing system synchronization settings.

## Sub-commands
_All arguments in `<value>` format are required. All arguments in `[value]` are optional. Attachments can be uploaded directly and privately using Discord application commands as opposed to uploading directly to the command message used._

 - `pb;sync settings` - Opens the visual configuration and settings layout for your system synchronization.


## Root Usage

Running `pb;sync` without any subcommands allows access to root execution options. You can also use the application slash command menu counterpart seamlessly.


### Application commands

Usage without any other sub-commands is supported with `pb;sync`, however is only allowed when not using Discord application commands. All root commands that have sub-commands must be used with prefix commands.
